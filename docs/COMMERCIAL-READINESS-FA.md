## ۵) شش اقدام باز — پیش از عرضه (نزد کارفرما/سازنده)

1. **پوش مخزن**: ۶ کامیت محلی (`35d6b8e` → `f613707`) به مخزن خصوصی + همگام‌سازی مخزن audit (با توکن تازه).
2. **توکن GitHub**: توکن لوک‌رفته قبلاً rotate شود (خارج از محیط توسعه انجام می‌شود).
3. **دو تصمیم باز ممیزی**: M11 (سیاست ضد سوءاستفاده ترِیال/ثبت‌نام آزاد — کد دعوت فعلاً «اختیاری» است) و M12 (باز کردن خواندن داده پس از انقضا — فعلاً طبق ۵.۴ فقط وضعیت/پشتیبانی/sync آزاد است).
4. **استقرار تولید**: متغیرهای env الزامی (DATABASE_URL بیرون از public_html، SETUP_TOKEN، BACKUP_ENCRYPTION_KEY، و روی نصب سازنده: OWNER_MOBILES + OWNER_SETUP_KEY + LICENSE_PRIVATE_KEY_PEM، VIZITO_ALLOWED_ORIGINS، TRUSTED_PROXY_HOPS=1 پشت Passenger) — راهنما: `docs/DEPLOY-CPANEL-FA.md`.
5. **APK**: بیلد از GitHub Actions با ورود دستی آدرس HTTPS سرور واقعی (نام آرتیفکت حالا v2.0.0 است).
6. **سخت‌سازی بعدی (فاز APK)**: انتقال کلید رمزنگاری محلی از localStorage به Android Keystore + پل نیتیو — حد فعلی به‌صورت شفاف در سربرگ `src/lib/idb.ts` مستند است.
